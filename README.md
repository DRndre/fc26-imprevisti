# Imprevisti Carriera FC26

App per estrarre 200 imprevisti prepartita e 121 di sessione nella modalità carriera di EA FC26, con controllo delle regole della rosa e tracker di infortuni e squalifiche.

I dati restano salvati nel browser in cui usi l'app. Usa "Copia backup" nelle Impostazioni per spostarli su un altro dispositivo.
